# 知行舟使用说明

从 [[首页]] 开始。这个文件夹本身就是 Obsidian 仓库；所有 `示例-` 笔记都是可删除的虚构演示。

## 第一次打开

使用 Obsidian 1.14.4 或更新版本，保留隐藏目录 `.obsidian`。在设置中启用核心插件“数据库（Bases）”“模板”“日记”“书签”，再启用随附的第三方插件“项目与任务”。详细安装步骤见仓库根目录的 README。

若首页显示不支持的视图或只有代码块，先检查“项目与任务”是否启用。插件停用时正文仍保留，但自定义项目列表、操作按钮和自动模板不可用。

## 项目与任务

1. 从 [[99-系统/数据库/项目.base|项目总览]] 或 [[99-系统/数据库/任务.base|任务清单]] 点击“新建项目 / 新建任务”。先填写名称和目标或行动内容，再补充分类、状态和日期。
2. 点击名称，在右侧打开详情；后续选择会复用右侧详情。按 `⌘E / Ctrl+E` 切换阅读和编辑。
3. 项目页的“新建本项目任务”会自动关联项目。独立任务的“项目”属性可以留空。
4. 简洁列表中的状态、分类和日期可以直接修改；行末“··· → 编辑属性”可集中编辑和改名。切换“表格”可查看更多字段。
5. 完成后把状态设为“已完成”。记录会退出待处理视图，在全部视图中保留。

在 `10-项目` 或 `11-任务` 的第一层新建空笔记，也会自动套用模板。已有正文不会被自动模板覆盖。不要在这些目录的子文件夹里依赖自动套用。

| 字段 | 约定 |
| --- | --- |
| 分类（属性名为“领域”） | 默认学业、工作、生活、兴趣，可以在插件设置中调整 |
| 项目状态 | 待确认、计划中、进行中、等待中、暂停、已完成、已取消 |
| 任务状态 | 待办、进行中、等待中、暂停、已完成、已取消 |
| 优先级 | P0 紧急、P1 高、P2 正常、P3 低；不确定可留空 |
| 截止日期 | `YYYY-MM-DD`，不确定可留空 |
| 进度 | 手动填写 0–100，不按任务完成数自动计算 |
| 下一步 | 当前最具体的一步，保持一句话 |
| 上下文更新 | 最近一次实质更新上下文的日期，手动维护 |
| 项目 | 任务所属项目的双链，独立任务可留空 |
| 参考知识 | 关联库内知识笔记、主题和论文 |

截止日期从近到远排列，无日期的记录仍出现在全部与待处理视图中。“到期与逾期”只显示未结束且已逾期或七天内到期的记录。“已完成 / 已取消”是结束状态，数据库过滤依赖这两个名称。

首页“全部任务”不预设项目排除条件。需要排除某个项目时，在当前视图的筛选菜单添加“项目不等于……”条件；移除条件即可恢复。

**一个行动只维护一份状态。** 项目里的普通复选框不属于独立任务，不会被 Bases 自动汇总。需要截止日期、优先级或跨项目追踪时，创建任务笔记。

## 参考知识、链接与灵感

- **参考知识**：打开项目的“编辑属性 → 添加参考”，搜索已有知识笔记、主题和论文，关联后会显示在项目页。
- **参考链接与课程**：点击“添加参考链接”，保存完整 URL、用途、摘记和学习位置。支持识别 YouTube、Hugging Face、GitHub 与普通网页；相同项目中的重复链接会提示补充原记录。
- **灵感与想法**：点击“记录灵感”，写下问题、想法或验证思路。内容保存在项目正文，自动附记录时间。
- **继续整理**：点击“编辑本区”修改内容；需要执行的想法再转为任务。点击“调整分段顺序 / 调整条目顺序”，拖动或用上下移按钮排序。

鼠标移到操作区域或附近的标题、说明文字时，项目按钮会显示；键盘 Tab 聚焦也会显示。触屏设备的按钮使用常显样式，但本项目尚未完成移动端验证。

## 想法、课程与播客

首页的“随手想法”和“课程与播客”使用原生 Bases 的新建、搜索、排序和筛选入口。

- 想法保存到 `00-收件箱/想法`，默认“待整理”；可改为待验证、已采用、已归档。项目可留空。
- 学习记录保存到 `20-知识/学习`。形式可以选择课程或播客；学习状态使用待开始、学习中、已完成、暂停；进度可以写“第 3 课”或“第 12 期 18:30”。
- 在对应目录第一层新建空笔记，会自动套用模板。点击名称在右侧打开，按 `⌘ / Ctrl` 点击则在新标签页打开。

“全部学习”按学习目录收录 Markdown 笔记，清空“类型”或“形式”不会让记录消失。

## 收藏收件箱与转换

从 [[00-收件箱/收件箱|收件箱]] 打开收藏名称，在右侧点击“转入…”。

| 转入位置 | 结果 |
| --- | --- |
| 兴趣项目 | 创建开源项目收藏，保留来源与摘要 |
| 未读论文 | 创建状态为“未读”的论文笔记，可填写主题；不创建任务 |
| 课程与播客 | 创建学习记录，可选择课程、播客、视频或文章 |
| 随手想法 | 创建想法笔记，“想法扩展”留空供自己填写 |
| 已有项目 | 选择项目，把链接和摘记加入“参考链接与课程” |

名称和来源自动填入，可在转入前修改。完成后保留原始收藏，标记“已整理”并写入“归档笔记”，结果在右侧打开。收件箱默认显示全部记录，已整理的收藏仍然可见。

同名笔记只有在来源链接相同，或已关联同一条原始收藏时才复用；已有正文不会覆盖。其他同名冲突会要求改名。同一项目中已有相同链接时不重复添加。转入后新增的摘记需在目标笔记中补充。

可用随附的演示收藏直接试用。自动同步和升级已有库的步骤见 [[docs/Raindrop收藏同步]]；没有显示按钮时，也可从命令面板运行“项目与任务：转入当前收藏”。

## 兴趣项目收藏

首页的“兴趣项目”用于收藏想了解的开源工具，记录来源、简介和关注点。点击“新建”会在 `20-知识/开源项目` 创建笔记并自动套用模板；正文用于记录项目内容和试用结果。点击名称在右侧打开编辑视图。需要投入执行时，再建立独立项目或任务。

## 论文、主题与知识笔记

一篇论文对应一份阅读笔记，用“未读 / 在读 / 已读”记录阅读状态。原文的来源与阅读理解写在同一页；附件可以放在 `90-附件/论文`，通过“来源”关联。

新论文先搜索是否已有记录，再从首页“未读论文”中点击“新建”，或在 `20-知识/论文` 第一层新建空笔记。已有记录继续编辑，不重复复制。

主题页通过“主题内容”数据库汇总指向它的知识。创建主题时，在 `20-知识/主题` 新建笔记并插入“主题”模板；在其他知识笔记的“主题”属性中添加该主题页的双链。

知识笔记用于整理可复用的概念、比较和方法。创建后手动插入“知识笔记”模板，保留来源与证据。示例论文卡片没有真实文献或结论，使用前请替换。

## 删除与恢复

行末“···”或详情页上的删除按钮会先确认，再把笔记移到本库 `.trash`。相关项目、任务和附件不会一起删除。

可以点击通知中的“撤销”，或从命令面板运行“项目与任务：撤销上次删除”。重启前的删除记录需要从 `.trash` 手动恢复；存在同名文件时不会覆盖。

原生表格中的 Backspace / Delete 用于清空单元格，不是删除整份笔记。清理演示时，可以搜索文件名以 `示例-` 开头的记录并删除；首页只链接通用入口，不依赖示例文件。

## 快捷入口

| 操作 | Mac | Windows / Linux |
| --- | --- | --- |
| 搜索并打开笔记 | ⌘O | Ctrl+O |
| 全文搜索 | ⌘⇧F | Ctrl+Shift+F |
| 插入模板（本库设置） | ⌘⇧T | Ctrl+Shift+T |
| 切换阅读与编辑 | ⌘E | Ctrl+E |
| 命令面板 | ⌘P | Ctrl+P |

日记保存在 `30-日志`。首页、项目、任务和知识库入口也已添加到书签。

## 同步与定制

模板没有配置同步账号、云盘备份或提醒服务。备份方式由你自行选择；可以将代码、LaTeX 等工程放在仓库之外，用链接记录位置。

目录、属性和章节标题的定制约定见 [[docs/开发与定制]]。若用 Git 管理笔记，请阅读根目录 README 的公开范围说明：默认忽略新个人内容，但已跟踪文件的修改仍可能进入提交。
